# M1: Road networks

M1 is the first milestone a player can do something in. They draw roads on the M0 map, the roads join into a network, and the sim can route across it. No traffic, zoning or money yet.

The full context is in [the PRD](../PRD.md), under "M1 Road networks". The three things rail needs from M1 are under "M7 Rail transport".

## Exit test

All of these pass in one Playwright walkthrough, on WebGPU where available and on the WebGL 2 fallback.

1. Draw a straight street. It appears on the map and in the activity log with a player id and a tick.
2. Draw a second street across the first. The first splits and a four-way intersection forms.
3. Draw a curved avenue whose end snaps to an existing node, and a road that snaps to 90 degrees off an existing segment.
4. Draw a road across water. The part over water becomes a bridge. A road up a slope too steep for its type is refused, and the preview says why.
5. The preview shows the length and the cost before the click. Nothing is charged, because the treasury arrives in M4.
6. Upgrade a street to an avenue in place. Bulldoze a segment. Undo both, one step at a time.
7. Pick two points on the network. The route between them is highlighted. Bulldoze the only link between them and the pathfinder reports no route.
8. Every outside connection at the map edge is reachable from a road joined to it.
9. Reload the page. The same network comes back.
10. A replay of the recorded command log from the same seed produces the same state hash.

## Numbers fixed for M1

| What | Value |
| --- | --- |
| Buildable road types | Street with 2 lanes, avenue with 4, one-way with 2 |
| Highway | In the data and at the outside connections. Not buildable until M5 |
| Network types | Road, rail and path are stored. Only road is buildable |
| Segment shape | A straight line, or one quadratic curve with a single control point |
| Vertical level | Stored on every segment. M1 writes ground and bridge only |
| Routing graph | One edge per direction per segment. A one-way has one edge |
| Outside connections | Two or three, fixed at the map edge, placed from the seed |
| Spatial index cell | One 500 m chunk, the same grid the renderer uses |
| Scale check | A generated network of 30,000 segments |

Speeds, capacities, widths, slope limits, curve limits and prices are set in `packages/sim/balance/roads.json` by issue 01. They are starting values to tune.

## Decisions to make inside M1

- **How a road meets the ground.** There is no terraforming, so a road follows the terrain. Issue 03 samples the ground along the path and refuses a road whose grade passes the limit for its type. If draped roads look wrong on rolling ground, the fallback is a straight grade between node heights with short embankments drawn by the client. Record the choice in the PRD.
- **What "bridges over water above a height" means.** I read the PRD line as this: where a road crosses water, that span becomes a bridge with its deck a set clearance above the water. Bridging a dry valley is left for M7, where elevated track needs it anyway. Issue 11 records this in the PRD. Say so if you meant something else.
- **Where derived data lives.** The spatial index and the routing graph are rebuilt from the graph arrays. They are not saved. Issue 02 picks one home for both, and tests that a city saved and reloaded mid-run behaves the same as one that never stopped. The M0 review asks for exactly this check.
- **The price of a local street.** The PRD lists it as still to price. Issue 01 looks for a source. If it finds none, the number goes in marked as a placeholder and stays on the PRD list.
- **What a failed undo does.** Issue 14 decides whether an undo that is no longer valid stays on the player's stack or is dropped.

## Out of scope

Zoning cells, buildings, pops, money changing hands, traffic volumes, overlays, highways and ramps as buildable roads, tunnels, elevated roads, rail and paths as buildable networks, transit lines, bike lanes, multiplayer.

Snapping to zoning cells is in the PRD list for M1, but the cells do not exist until M2. It moves to M2.

Junction types with delays, such as signals and roundabouts, belong to M5.

## One risk to settle early

The PRD names the road tool as the hardest client work in the project. So the order below gets a playable slice first: straight roads, intersections, rendering and a basic tool by issue 07. Curves, snapping and bridges come after that. The sim graph never depends on the mesh, so the visuals can improve without a new save version.
